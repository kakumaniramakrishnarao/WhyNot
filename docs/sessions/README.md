## Card format

- **Goal** — the outcome in one or two sentences.
- **Depends on** — sessions that must be ticked in `PROGRESS.md`.
- **Read first** — docs to read fully before coding.
- **Skills** — Codex skills to use.
- **Build** — the exact deliverables (files/modules). Nothing else.
- **Tests** — tests that must exist at the end.
- **Done when** — objective checklist; all must be true.
- **Out of scope** — tempting things *not* to do.
- **Starter prompt** — paste into Codex as-is.

How to run a session, review it, and merge it: [`docs/09-codex-workflow.md`](../09-codex-workflow.md).
